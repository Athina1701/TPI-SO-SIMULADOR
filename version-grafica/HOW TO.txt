# EJECUTANDO SOBRE LA CONSOLA TRADICIONAL:

-Abra/seleccione el archivo: simulador_equipo2.py que se encuentra en la carpeta "version-grafica"

    --Ejecutando desde la consola de VS Code:
        Presione Run Code y automaticamente inciará

    --Ejecutando desde una Terminal Externa:
        Presione ctrl+shift+c para abrir la terminal.
        Estando allí, escriba: python + ruta del archivo principal:
            python version-grafica\simulador_equipo2.py 
        o...
            python simulador_equipo2.py

    -- Hecho lo anterior, automaticamente aparecerá el menu.
    Presione "2" para comenzar el simulador.
    Tendrá 2 opciones de carga de procesos: 
        1-- Cargar archivo existente:
            Se le pedirá:
            > Si el archivo se encuentra dentro de la carpeta del programa ejecutable: Copiar la ruta de acceso (Relativa o no) del archivo donde contiene los procesos. 
                Ejemplo: C:\Users\athin\Downloads\labPython\TPI-SO-SIMULADOR\procesos.txt o version-grafica\procesos.txt
            > Si el archivo no se encuentra en la carpeta: copie la ruta de acceso completa del archivo y recuerde borrar las comillas que aparecen: 
                Si se pega: "C:\Users\athin\Downloads\archExternoPruebaProcesos.txt"; borre y que quede: C:\Users\athin\Downloads\archExternoPruebaProcesos.txt
                O abra el archivo con VSCode y copie la ruta de acceso desed VSCode.
        
        Una vez pegada la ruta de acceso, presione enter y comenzará el simulador.

        2-- Cargar procesos manualmente:
            Primero se le pedirá el nombre del archivo (no debe ser igual a uno existente);
            Presione enter y se le permitirá comenzar a cargar los procesos; 
            es un proceso por linea; el orden es: ID proceso, TA, TI, Tamaño (Puede copiar y pegar varios procesos seleccionados, mientras esten con salto de linea).
                Ejemplo:
                    P1,2,5,50
                    P2,2,1,70
                    P3,0,4,120
                O separado por espacios:
                    P1 0 10 100
                    P2 0 1 80
                    P3 0 12 120
                    P4 0 2 90
 
            Para terminar de cargar procesos, presione enter en una linea vacia.
            Comenzará la ejecucion del simulador, si todo está correcto.

    Las prsentaciones de salida se muestran por cada proceso terminado, y po rcada proceso arribado o recien admitido al simulador.
    Al final se muestran Los promedios de tiempo y Rendimento del Sistema
